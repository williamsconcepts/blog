# 📝 Blog API

A RESTful blog backend built with **Express.js, Knex.js, and SQLite**.

This API allows users to create blog posts, manage categories, comment on posts, like posts, and rank posts based on popularity.

---

# 🚀 Features


## Posts

- Create posts
- View all posts
- View single post
- Update posts
- Delete posts
- Like posts


## Categories

- Create categories
- View categories
- Assign categories to posts


## Comments

- Comment on posts
- Link comments to posts
- View comments by post


## Popular Posts

- Rank posts by:
    - Likes
